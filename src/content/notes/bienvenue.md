Cette note est un brouillon : elle n'apparaît pas dans la liste tant que `brouillon: true`.

Pour ajouter une note, créer un fichier Markdown dans `src/content/notes/` avec `titre`, `date`, un `resume` facultatif, et passer `brouillon` à `false` quand elle est prête.
